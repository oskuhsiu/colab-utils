# ComfyUI 現成 workflow 與節點 inventory

查核日：2026-10-10。只讀公開 web/HTTP；未登入、未安裝 custom node、未下載權重、未啟動 GPU。本檔只盤點可直接取得的 ComfyUI UI JSON、官方/作者節點包、節點輸入契約與一手輸出紀錄；不把 workflow 存在推成畫質最佳，也不把非指定 GPU 的結果外推成 L4 或 A100。

## Answer

目前可直接拿來作候選的流程分成四群：

1. 官方 native：MiniMax H3 T2V/I2V/R2V、FastH3 V2 T2VA/FL2VA、Wan VACE、Wan Animate、Hunyuan Video。
2. 作者 nodepack：Kijai WanVideoWrapper、Kijai FramePackWrapper、Lightricks ComfyUI-LTXVideo。
3. 專門控制流程：VideoX-Fun Wan2.2 VACE-Fun、FastH3 VSA 4-step experimental。
4. 低資源/後製社群流程：city96 ComfyUI-GGUF + Cordux Wan2.2、safzanpirani Wan2.1 GGUF + upscale + frame interpolation。

沒有找到任何一條上述 workflow 在同一 prompt/seed/resolution/frames/precision 下，同時提供單 L4 24GB、單 A100 40GB、單 A100 80GB 的完整成片、時間、peak VRAM、host RAM 與品質驗收。表中的 `unknown` 是查核缺口，不代表不可跑。

## Compatibility and evidence gaps

- **容量單位。** 表內模型19.53／14.61等值照template標籤記錄；至少Qwen14.61的數字對照HF十進位約15.7GB接近GiB口徑。不能以這些近似標籤算VRAM；應核exactbytes與GB/GiB。工作區42.36GB／39.45GiB四資產合計另見00，版本／VAE也可能不同。
- **舊本地證據另列。** WF09的upstream graph／README未給本分題新增L4測試；工作區已有pinned／適配後的L4 200 VSA calls／0 fallback記錄，見00，不能當所有上游workflow已驗。

- **UI JSON 與 API JSON 不同。** 本檔多數 artifact 是 ComfyUI editor/UI JSON，含 `nodes`/`links`/`extra.frontendVersion`；不能直接當 API prompt body。WF10、WF13、WF14尤其含自訂 node metadata；需先在對應 ComfyUI/nodepack 版本載入，API 另行 export。
- **權重/節點型別不能按名稱混用。** H3 FL2VA 與 Ref2VA 用不同 diffusion model；FastH3 V2、FastH3 V1 VSA、H3 Turbo LoRA 是不同 step/sigma/attention contract。Wan native、WanVideoWrapper、VideoX-Fun 的 model object 也不同；Kijai 明示 node-specific inputs 不能任意互換。
- **offload 只在來源明說時記錄。** WF08 的 `sequential_cpu_offload`、WF13 的約 9GB CPU offload、WF07/WF11 的 node-level block/offload controls 是 graph/README 設定，不是 L4/A100 peak RAM 實測。其餘 host RAM、pinned memory、disk cache、torch.compile/cache fallback 多為 unknown。
- **現有指定 GPU 證據缺口。** 直接找到的時間多是 4090、RTX3050、5090 或未標 GPU 的 local output；沒有新增 L4/A100 執行。A100 40/80 不可由模型檔大小、steps 或 4090 旁證外推。
- **需要額外輸入的流程。** H3 I2V/R2V、VACE V2V、Animate、VideoX-Fun V2V、FramePack 都需要 image/video/audio/reference/pose 等素材；只有 T2V graph 不需 extra media。WF05 VACE inpaint/outpaint 文件部分仍標為待更新，未列為完整可跑 contract。
