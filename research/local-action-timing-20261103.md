# 局部動作速度：從劇本到實際提示

2026-11-03。回應使用者指出成片所有動作都以同一慢節奏演出，尤其意外失足不應緩慢下落。此修正延續 draft PR #3，不以先前文件已有提醒視為問題已解決。

## 查到的缺口

既有 `intrashot-staging.md` 已區分動作速度、生成片長與剪入長度，但執行鏈仍有落差：

- `dialogue_timing.plan_timing` 的 `action_end_seconds` 只參與總片長預算，沒有動作內容或局部時窗。
- 原 `pacing_prompt` 只插入台詞，無台詞直接返回 base。因此分鏡的時間線仍需人工重寫，沒有語音時間線同等的編譯交接。
- Studio 的獨立錄音分支只編預算，不改視覺 prompt；獨立 Omni runner 只讀最終 `job.prompt`，沒有處理 timing metadata。
- H3/Wan backend 和原生 ComfyUI conditioning node 接收的是最終 prompt，不會自行讀懂前製的節奏標註。

這證明存在上游交接缺口，**不證明既有成片的全部成因**。本次未取得／重看使用者所指原片，也未做新的模型生成。模型自身的時間遵循、控制素材或剪輯仍可能影響實際效果。

## 最小修正

在既有 timing spec 加可選 `action_beats`，每窗只需起訖與具體動作；`playback` 只區分實時與明確藝術慢鏡頭。普通行走、快速反射、慢速精細操作由動作描述和窗口表達，不設速度枚舉、關鍵字推理、全片加速或快慢配額。

- 窗口用片內畫面秒數，允許並行與稀疏標註；片長取較晚末點，不把並行事件相加。
- 模型下限、長旁白、固定長鏡頭和 frame 量化只決定容器長度，不伸縮局部事件或語音。
- 動作寫入 H3 原有動態欄位／Wan 一般 prompt；無台詞和獨立錄音也支援。錄音的台詞邊界、聲線及音軌不被改寫。
- 原生 ComfyUI/Pika 沿用 `compile-api`。獨立 Omni 用同一工具的離線 `compile-job`，再把最終 JSON 交回原 runner；未編譯 timing 會被拒絕而非忽略。遠端封裝、GPU 流程和回復依賴不增加。
- Studio 的動作描述沿用實際已供圖的 typed-reference 解析；其他編譯入口要求已解析 labels，不猜資產名稱。
- 不變更 backend 物理控制、模型時長限制、預算、提交狀態機或最終內容驗收。原本已完整寫好的最終 prompt 不必改成新表。

寫稿／拆鏡規則同步把物理動作、運鏡、戲劇節奏與播放處理分開。需要時只交代必要的進入狀態、觸發至結果、事後反應，不強制三段式。突然事件不靠漫長預警、預備蹲姿或角色提前驚恐來「建立因果」。

## 離線回歸範圍

`tests/test_action_timing.py` 使用手寫內容和未實測秒數，透過真正的 compiler、Studio job、原生 graph 與 Omni 離線 bootstrap 封裝測試：

| 內容 | 要保留的差異 |
| --- | --- |
| 碰熱物抽手 | 觸發後短促反射，不因慢推鏡或長旁白而伸長 |
| 鑰匙掉落碰桌 | 短促掉落、接觸及一次彈跳 |
| 日常行走、遞杯 | 正常速度，不因修正而全部加快 |
| 精細旋螺絲 | 實時緩慢操作，不誤當慢鏡頭 |
| 安靜場景中木板突然斷裂 | 普通進入 → 短促失衡 → 較慢恢復；不提前反應 |
| 明確藝術慢鏡頭 | 保留指定窗口的慢鏡頭，其他窗口可實時 |
| 對白／長旁白／匯入錄音並行 | 語音與動作各保留自己的起訖，不重複台詞或串行相加 |

木板案例保留**僅左腿陷至大腿、雙手撐洞緣、右腿仍有支撐而截住下墜**，不是全身浮落；數字不是對此事件的實測物理結論。通用實作不含小說、人名、失足或掉落關鍵字分支。

測試核對窗口值、實際 prompt 中完整動作與所屬動態欄位、台詞不重複、模型／素材／採樣設定不變，以及新事件改變生成 digest。Omni 測試將編譯 JSON 送入 `graph_for_job` 和 `bootstrap.prepare`，確認封裝的 job／graph 完全對應；不是只檢查文件有沒有出現某個關鍵字。

## 驗證界線

這次建立的是**可驗證的動作時間意圖傳遞**，不是真實物理求解器，也沒有證明模型會遵從窗口。尚未做付費模型、GPU、TTS／ASR 或新影片測試；沒有實測成片改善、成本或時長變化。未來在既有授權內生成後，仍須正常速度看觸發、位移、接觸、支撐與止住的過程，再輔以密集影格；不能把 prompt 正確或單張姿態當成速度已成立。

測試與多位獨立 Astra/max 最終審查結果記在 PR；不新增正式製作的必跑模型呼叫、評審層或每鏡必填表。
