# 連續場景、動作節奏與情緒行為：文字回歸檢查

這次修改先改善劇本與交接方式，不新增生成器或品質評分器。原有文件已要求因果、完整互動、語速與情緒強度，但仍容易被用成「每鏡各自填完整」的工作：鏡頭摘要取代連續場景，模型片長反過來決定動作速度，情緒欄位填了卻沒有改變行為。

以下以使用者提供的《穿越後的美好人生》第1章〈死人的床〉情節做兩個短段落的紙上比較。這是重新編寫的動作稿，不是原文引句，也不是已生成影片的逐字轉錄。「修改前」是針對回報問題重建的反例，不能當成三個分支的實測輸出或因果證明。本次未重看既有成片，無法斷言問題全由 repo 規則造成。

## 本次改什麼、不改什麼

- 先在既有稿件寫能連續演出的場景，再拆視角、鏡頭及模型工作；不加一份必填文件。
- 未指定總時長時，從內容估片長，不自訂分鐘數、秒數區間或鏡數去填滿。使用者明定的總時長仍保留；內容放不下時說明取捨。
- 分開動作速度、生成長度與剪入長度，避免快事件被平均攤滿片段。剪短無效等待，不刪掉建立發現與因果所需的過程。
- 讓情緒改變行為策略。保留 E0–E4、felt／shown 作有需要時的交接輔助，不要求每鏡填強度表。
- 在原有審稿及成片驗收中連讀／連看整場與相鄰段落，不加 reviewer 層、schema、資料庫、模型呼叫或 GPU 支出。

PR1 的成本／來源／驗收邊界與 PR2 的參考解析、錄音時間軸不變。本次沒有更改 Python、JSON 契約、模型片長限制或使用者交付時長的驗證。 H3 的本地提示說明同步採按需分級，並訂正既有 `silent_mouthed_inner` 已受 compiler 支援的事實；可編譯提示意圖仍不代表實片表演已驗證。

## 片段 A：撐身坐起到發現乾屍

**必留事實**：希昂在全黑中噁心乾嘔；想撐身坐起，手先碰到不像石面的乾皮，遲疑後摸索，指尖碰入眼窩再碰到牙齒，才確認是屍體；抽手後退撞上石壁，忍住疼痛。辨認依觸覺，不能看見黃牙或提前補光。

**修改前，問題反例**

> 希昂醒來，感到恐懼。下一段：他摸索乾屍的臉，看到黃牙，驚恐退後。每段用一段模型片長，分別標上強烈恐懼。

缺口不是少了一個「轉場」：第一個動作為何變成摸屍沒有建立；「乾屍」已先替角色作了辨認；全黑卻看見黃牙，改變了資訊取得方式。相同強度標籤也沒有呈現由不明觸感到確認屍體的變化。

**修改後，連續可演稿**

> 希昂被噁心逼醒，黑暗中乾嘔。他伸手想撐起身，掌下卻不是預期的石面，而是一層乾硬的皮。手停住。片刻遲疑後，指尖沿那表面摸索，陷進眼窩，再碰上硬而密的牙齒。他猛地抽手，身體向後縮，背撞上石壁；痛得吸了口氣，又把痛呼壓回去。

這段沒有新增口說台詞。觸感、動作聲、呼吸與必要的既有心聲可按原改編方式承載；黑暗仍維持，不為拍清細節點亮「劣質明光火盆」。若影像看不到接觸細節，不能把文字中的眼窩／牙齒自動算成成片已可讀，須另外核對聲畫是否讓觀眾理解發現過程。

**拆鏡時保留的關係**

- 可以連續演出，不為「醒來／碰到／辨認／後退」各增一鏡。需要換視角時，在既有摸索過程切入，後鏡承接同一次接觸，不重演伸手，也不突然變成已知的檢查屍體。
- 摸索與遲疑需要辨認時間；抽手、撞壁是突發反應，忍痛發生在撞壁後。不要把四者平均分配秒數。
- 想坐起被異常觸感打斷，試圖弄清楚被認出屍體打斷，逃離接觸又被石壁打斷。情緒由這些行為改變可讀，不只寫「更害怕」。

## 片段 B：爛木板斷裂、單腿陷落與抽腿

這是稍後的另一段，不暗示 A 結束後立即跨到木地板；中間情節仍須按完整來源保留。

**必留事實**：希昂謹慎走過腐朽木地板，板子突然斷裂；只有左腿陷到大腿，雙手撐住邊緣，右腿仍提供支撐。止跌後才有疼痛、遲疑與緩慢抽腿。不是全身墜落，也不是在空中慢慢飄五秒。

**修改前，問題反例**

> 他踩上爛木板。五秒內緩慢落入坑中，表情恐懼。下一段重新交代他陷在洞裡，接著抽腿。

此安排把生成片長誤作下墜時間；省略支撐如何止住墜勢，又在下一片段重新開始同一結果。整段加速不能補回單腿、支撐與疼痛先後，也可能壓縮真正需要較慢的抽腿。

**修改後，連續可演稿**

> 希昂試探著把重量移向前腳。木板突然斷開，左腿一下陷至大腿；他雙手撐住洞緣，右腿仍踩在未斷的地板上，將身體截住。疼痛追上來，他不敢立刻硬拔，先穩住支撐，再一點點抽出左腿。

**速度與剪輯安排**

- 斷裂、左腿陷落、手撐止跌是一個短促的失衡過程；前面的試探及後面的忍痛抽腿可慢，不能拿它們的總時間當成下墜時間。
- 模型需要較長生成時，允許容納前後動作，再選完整有效區間；不要求動作持續到生成結尾，也不為剩餘秒數重做試探、跌落或疼痛反應。
- 切到止跌後的狀態時，左腿深度、雙手支撐、右腿位置及疼痛都承接前段。不能用一個相容的末態倒推模型已演出止跌過程。

## 情緒反差：同樣害怕，不是同一套表情

摸到乾屍時是意外接觸引發的抽手、後縮與撞壁；稍後聽到門外刮擦，希昂雖想逃，卻怕驚動門外的東西而停住、屏息並握緊剔骨刀。後者的強烈恐懼表現在阻止自己動，不是重演大幅後退或喊叫。這是來源情境的對照，沒有新增怪物身分、外觀或設定；火盆仍未點燃。

## 本次紙上判讀與驗證界線

| 檢查面向 | 反例中的問題 | 改稿中的可查依據 | 仍待實片確認 |
| --- | --- | --- | --- |
| 動機與發現 | 醒來直接摸已知乾屍 | 撐身意圖 → 異常觸感 → 摸索 → 辨認 → 抽手 | 黑暗中的聲畫能否讓觀眾跟上，不提前揭露 |
| 物理與時序 | 全身慢墜，沒有支撐過程 | 左腿突陷、雙手及右腿止跌，之後才忍痛抽腿 | 模型是否真的做到短促失衡、正確肢體與重量感 |
| 情緒行為 | 全部只標強烈恐懼 | 發現後逃離接觸，門外威脅時主動抑制逃跑 | 演出、呼吸與聲音是否有足夠反差而不誇張 |
| 相鄰連續性 | 下一段重新描述已發生結果 | 切點沿用正在發生的動作、支撐與情緒末態 | 實際素材及剪輯是否接得上 |
| 節奏取捨 | 每段填滿同樣片長 | 辨認／試探可停，突發動作快，必要反應保留 | 即時觀看整場後，等待是否仍有作用 |

這些結論是對兩段文字設計的判讀，不是客觀藝術分數，也沒有量出成片縮短比例、成本節省或品質提升。文字較連貫不保證模型會遵循提示；密集抽幀不能取代即時觀影，音量／字幕不能取代聽驗。

維護檢查沿用 `python3 scripts/install_repo_skills.py --check`、`python3 -m unittest discover -s tests -v` 及 `git diff --check`，另查本次 Markdown 的本地連結。沒有為關鍵字或「藝術品質」新增測試數；離線測試只驗既有工具契約未受影響。發布前的多位獨立 Astra/max 審查、最終版本與測試結果另記於 PR 描述。
