# ComfyUI H3 extension source report (checked 2026-10-19)

Implementation scope: the user subsequently deferred Veda. It remains research
only; the new workspace installs Continuum and Ref2VA-VSA, with no Veda node,
predictor, or model bundle.

The three public repositories were queried on 2026-10-19, then fetched as
source-only shallow checkouts. `git ls-remote` identified the current default
branch as `main` in each case. No upstream code was executed and no
dependencies were installed.

## Answer

At the checked commits, Veda is a native H3 attention override for T2VA,
FL2VA, and R2VA; H3 Continuum is a chunked native AV continuation/session
extension whose current V3.9 workflow uses FL2VA; Ref2VA-VSA is an
experimental R2VA-specific transplant of 50 FastH3 gate matrices followed by
the tile-64 Sol/VSA patch. Their declared dependency and compatibility
surfaces are different; none of these sources pins the user's existing
FastH3/ComfyUI commits.

## Uncertainty / Search boundary

- Model weights in all three repositories are linked by upstream `main` URLs; only Veda's predictor artifacts carry exact revisions and SHA-256 values in repository source. I found no model hash/revision metadata for the Continuum or Ref2VA model files.
- Continuum's current `main` is newer than the published `v3.9.8` release tag (`58fbd855feb13fa67a0613614df04e2b6fe808e2`); the report records `main` as requested and labels release-only validation separately. Its docs explicitly name audited attention/Spectrum profiles but do not mention FastH3/VSA.
- No source here validates the user's existing FastH3 ComfyUI commit `a4b5a045e56fc334903db8457b728b64e006119c`, FastH3-VSA export `c1798183d89f7143d021c16507e4bb7ac0b3decc`, or L4 hardware. Performance and hardware entries above are upstream claims under the stated conditions.

## Main attention

The decision-relevant source boundaries are Veda's attention ordering and predictor pins, Ref2VA-VSA's hard rejection of existing attention/block patches, and Continuum's narrower audited-provider acceptance despite its statement that it preserves existing attention overrides.
