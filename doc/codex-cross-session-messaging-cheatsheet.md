# Codex 跨 Thread／Session 傳訊 Cheatsheet

## 常用指令

| 想做什麼 | 直接這樣說 |
|---|---|
| 查看可存取的對話 | 列出這台電腦可存取的 session 標題與 ID。 |
| 查某個對話的 ID | 查出對話「〈標題〉」的 thread ID。 |
| 查看另一個對話 | 讀取對話「〈標題或 ID〉」的最近內容與狀態。 |
| 傳給主對話 | 請跨 thread 轉達給主對話：〈內容〉。 |
| 傳給另一個 session | 請把〈內容〉傳給 session「〈標題或 ID〉」。 |
| 傳送後查看回覆 | 請把〈內容〉傳給對話「〈標題或 ID〉」，並讀取它的回覆。 |
| 整理後轉達 | 把我們剛剛討論的結論整理後，傳給對話「〈標題或 ID〉」。 |

## 對應工具

| 工具 | 用途 |
|---|---|
| `list_threads` | 列出可存取對話的標題、ID 與狀態 |
| `read_thread` | 讀取指定對話的內容與狀態 |
| `send_message_to_thread` | 向指定對話傳送後續訊息 |

明確指定工具的說法：

> 使用 `send_message_to_thread`，把〈內容〉傳給對話「〈標題或 ID〉」，並回報是否成功。

## 目標與確認方式

| 項目 | 要點 |
|---|---|
| 用標題指定 | 通常足夠，agent 會查出對應 ID |
| 用 ID 指定 | 精確定位，適合同名對話 |
| 「主對話」 | 在側邊對話中，指其來源主對話 |
| 同電腦不同 session | 目標需能被目前的跨 thread 工具存取 |
| 獨立 CLI session | 先確認工具是否能找到及存取 |
| 傳送成功 | 表示訊息已提交；對方是否回覆或完成工作需另行確認 |
| 上下文 | 傳送指定內容；需要背景時可要求先整理摘要 |
