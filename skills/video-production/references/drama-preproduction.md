# 短劇前製：劇本、資產與鏡頭交接

用於小說改編、短劇、多集故事或需要共用角色／場景／道具的敘事影片。依本次工作採用需要的部分；已有合用劇本或只改一鏡時，直接沿用既有內容。此頁含整理改寫的上游內容與可複用模板，來源、修改說明與授權見文末。

## 先定劇情，再定鏡頭

保留指定情節、人物關係和必留台詞，先把一場戲寫成可連續演出的動作與聲音，不先列鏡號、每鏡秒數或模型片段。已有劇本就直接修原稿。場次、內外景、地點與時段交代情境；景別和運鏡留到分鏡，避免修改取景時連帶改掉故事。

連讀時檢查角色此刻要做什麼、什麼觸發了下一步、如何取得新資訊，以及結果如何改變行動。例如「醒來 → 摸屍」缺少發現過程；「想撐身坐起，手先碰到異物，遲疑後摸索辨認，確認是屍體才抽手」才交代這次觸碰為何發生。不要提前把未知物叫成角色已認出的東西；黑暗中的觸覺與聲音也能承載發現，不為了看清而無故補光或提前揭露。

不是每個因果都要展示全部小動作。保留會改變觀眾理解的發現、選擇與結果，刪併重複反應；觀眾能自行接上的日常動作可省略。有意跳時／蒙太奇按敘事目的提供線索，不強迫所有場景連續實時演出。

未指定總時長時，依完整表演、台詞試讀和必要停頓估計片長，不先設分鐘數、秒數區間或鏡數再填戲；試估可隨內容修訂。使用者明定的時長仍須遵守，先刪併可調內容或改剪法；必要內容確實放不下時說明取捨，不擅改要求，也不用慢動作、停頓或旁白湊長度。

含角色表演或語音時，依 [情緒與表演](emotion-and-performance.md) 讓角色欲望、阻礙與情緒轉折改變具體行為，再選需要的強度標註協助交接，不用逐鏡打分代替寫戲。逐句區分口說、心聲、無聲說話、畫外口說與旁白，標明嘴型、聲音聽感及可聽對象；場次與鏡頭切換均須承接已成立的情緒。

## 以當集需求整理共用資產

先看現有資產，再補當集實際出現的項目。給人物、場景及關鍵道具穩定 ID，另記名稱與別名；別名可協助查找，遇到同名人物或不同外觀狀態時人工確認，避免誤合併。

| 類別 | 要保存的基準 | 何時另建變體 |
| --- | --- | --- |
| 人物 | 身分與關係、可辨識五官／體態、髮型、服裝、原始參考圖 | 劇情需要的換裝、年齡或受傷狀態；保留與同一人物的關聯 |
| 場景 | 地點、時段、出入口、主要陳設相對位置、光源及背景圖 | 晝夜或布置改變會影響接戲時；沿用原場地的空間基準 |
| 關鍵道具 | 材質、形狀、比例、顏色、辨識細節與基準圖 | 劇情造成破損、開合、內容或持有人改變時，記下狀態 |

優先為推動情節、需要特寫或反覆辨認的物件建立獨立道具資產。普通陳設留在場景描述，常規穿戴留在人物造型；沒有關鍵道具就留空。資產投入生成的數量按用途與預算決定。

基準圖按用途寫提示：新建或補製人物圖依 [人物參照](character-references.md) 準備乾淨背景、臉部細節及所需角度，沿用選定身分核對各圖；場景圖以無人物的空間建立圖交代出入口、前中後景與固定布局；道具圖以乾淨背景完整呈現物件、比例和邊緣。人物、場景與當鏡起幀各有用途，實際送入影片的圖按模型契約選取。使用者提供的照片優先保留為原始基準。

## 分開故事段落、剪輯鏡頭與生成工作

故事段落可以包含多個鏡頭；一個生成工作能否完成這些切鏡，取決於實際模型與已驗證能力。需要可靠切鏡時，拆成可生成的鏡頭後剪接。把每鏡的敘事目的、場景／角色／道具 ID、聲音、可見動作、初末態及接點寫清楚，讓生成與剪輯使用同一份內容依據。

按 [段內時間線與具體表演](intrashot-staging.md) 決定鏡頭長度，並細化同一鏡頭內的動作、注意力與說話輪替；將片內時間窗與實際切鏡分開標記。

台詞以自然試讀或已有音軌估時，再留動作、停頓及反應時間。容納不下時調整剪輯或拆鏡；旁白和對白保留原文及說話者，避免提示詞轉寫時新增情節。

## 從分鏡轉成模型提示

- **靜態起幀**：描述起始構圖、人物位置、外觀、場景和光線，選能支持後續動作的狀態。
- **動態內容**：將段內時間線轉成按順序發生的觸發、具體動作、注意力／表情反應及結果，保留當段的機位與空間關係。
- **聲音**：分清逐句發聲方式、表演、嘴型、可聽對象、環境音與配樂，標出說話者及對應時點。聲線身份跨鏡保留，語氣依當場情緒變化。依模型是否支援原生語音與所需控制，決定送入生成或留給後製。
- **參考綁定**：從資產 ID 追到實際檔案、用途和輸入順序，再轉成所選 backend 的語法。H3 使用 [H3 提示契約](../../minimax-h3-colab/references/official-prompting.md)；Studio 使用 [資料與執行契約](../../colab-video-studio/references/workflow.md)。

上游的 `@名稱` 由其應用程式替換成圖片參照，其 `read_*`／`save_*`／`update_storyboard` 也是該後端工具。此 repo 不提供那些呼叫或任意 `@名稱` 猜測替換；可用 [Studio 的確定引用解析器](../../colab-video-studio/references/reference-audio.md) 將 typed ID／名稱／variant／view 編譯到實際 inputs 與 H3 picture 次序，缺少或同名時拒絕而非挑第一張。專案風格也須送入最終提示或已驗證的模型設定，不能假設有上游的自動注入。

提交前逐項比對分鏡標註與最終提示，確認強度對應的具體反應、`delivery`、發聲方式和嘴型等意圖實際傳入，避免編譯器漏讀欄位後只剩共用語氣。強度碼及其他前製欄位不會自動變成 backend 參數。

新語音 job 依 [對白估時與語速](dialogue-pacing.md) 編譯，將逐句表演放進 `utterances[].delivery`，台詞放 `text`，強度標註保留在前製／shot，不混入 timing schema。分開安排發聲、停頓與反應，以完整互動決定鏡頭長度，避免情緒分級變成逐句拆鏡或放慢台詞的理由。

## 可複用的前製模板

將下面需要的欄位合併到既有劇本／製作筆記，刪掉不適用與可直接繼承的欄位；不要求每鏡重填整表。這是內容交接表，不是新增的提交關卡；提交前另轉成實際工具接受的 job。

```markdown
# 作品／集次
目的、受眾、來源與改編範圍：
使用者指定時長（未指定則不設目標）、比例、語言、聲音、工具與預算：
必留事件／台詞與來源位置：
全片角色目標與情緒進程／預期觀眾感受：

## 場次與劇本
場次 ID／地點／內外景／時段：
可連續演出的動作、台詞、說話者與必要聲音（先於拆鏡）：
角色目標／情緒觸發與轉折／本場末態及情緒交接：
重要情緒轉折及依據／必要時用 felt、shown 與 E0–E4 協助比較：
本場的新資訊、結果與下一場交接：

## 當集資產
資產 ID／類別／名稱與別名／來源檔案：
外觀或空間基準／當集狀態與變體／出現場次：
參考圖用途／需新增或可沿用的素材：
人物角度與景別覆蓋／衍生圖身分核對／各鏡實際選圖：

## 鏡頭（按需要重複）
鏡頭 ID／所屬節拍與場次／敘事目的：
場景 ID／人物 IDs／關鍵道具 IDs：
景別與運鏡／預計剪輯長度／生成長度：
片內時間線（各窗的起訖、具體動作與結果、注意力／表情、聲音與嘴型；實際切鏡另標）：
初態 → 可見動作與結果 → 末態／下一鏡接點：
初始情緒 → 觸發與可見反應 → 結束情緒／觀眾感受：
本鏡改變的行為／壓抑或偽裝的原因（若有）；其餘承接場景，不重填強度表：
逐句台詞原文與說話者／voice_mode／delivery（重音、語速、氣息、停頓）：
逐句發聲估計或含句內停頓的實測／句後停頓與反應／編譯後 timing report：
說話對象／說者與聽者的視線、姿態及反應時機：
逐句嘴型／聲音聽感與位置／可聽對象／語音時點：
聲線身份／環境音、動作音效與配樂時點：
起幀提示／動態提示／實際參考檔案與輸入順序：
必須看見或聽見的證據／如何辨別偏弱或過度／尚待試片的能力：
```

交接前，先隱去鏡號與秒數，連讀當場及相鄰段落：下一步的動機與發現是否成立，切點有無重啟已演過的動作，快事件與事後反應是否被平均攤長，情緒是否真的改變行為。這是既有審稿的一部分，不增加一次審查角色或必填報表。再確認重要情節都有鏡頭或聲音承載、資產引用可解析、台詞與情緒反應放得下、發聲與嘴型一致，以及每個工作能送入所選模型。局部修改時更新受影響的鏡頭與資產關聯，保留其他已成立內容。前製完成只代表可進入製作；成片依 [video-production](../SKILL.md) 的剪輯與驗收流程檢查。
