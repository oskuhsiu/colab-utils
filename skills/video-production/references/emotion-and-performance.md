# 情緒與表演：從劇本到實際聲畫

含角色表演、對白或內心話的敘事片在生成前使用本頁。局部修正只處理受影響的表演與接點；單純轉檔、裁切或無角色的素材處理不必建立整套情緒設計。此頁是共用製作規則；各模型的提示語法與能力另按其輸入契約。

## 先寫角色為何有感受

在劇本階段整理每場的角色目標、在乎的得失、知道與誤解的資訊，以及新事件如何改變其情緒；另記希望觀眾感受到什麼。角色當下的感受與觀眾的感受可以不同，例如角色自得其樂，觀眾已從背景察覺威脅。

按事件安排情緒進程與反差，延續前場實際末態。場景切換本身不表示角色已冷靜；必要的緩和、掩飾或情緒反轉要有理由。刻意冷靜、麻木或死寂也可服務故事，明確交代其用途與其他角色的反應，而非讓所有角色共用一種平讀語氣。

把心理描寫分配給可見反應、行動、必要心聲或旁白；按故事的敘述觀點選擇，保留重要原意。原文的「想／心道」、說話動詞、唇語動作與改編安排是判斷發聲方式的依據。

## 依劇本判定情緒強度

對每位角色的重要節拍，先判定情緒種類，再用 E0–E4 五級記錄強度。喜悅、憤怒、悲傷、恐懼、羞恥等正向或負向情緒都適用；級別不代表正面／負面的排序。這是當部作品內的創作與交接標尺，不是心理量測、模型參數或跨作品可精確比較的分數；使用者已給的表演尺度與示例優先。級別用來選擇表演及辨認落差，不能只把「E3」送給模型。

| 等級 | 意義 | 劇本與表演的判斷錨點 |
| --- | --- | --- |
| E0 中性 | 沒有當前目標情緒，或外顯上沒有表露該情緒 | 沒有要求此情緒改變當下行為；沉默、麻木或僵住不能因此自動判為 E0 |
| E1 輕微 | 情緒可察覺，但尚未主導注意力或行動 | 短暫遲疑、帶笑或不悅後，仍自然完成原動作／語句 |
| E2 明確 | 情緒清楚影響語氣、注意力或行為，角色仍能順暢應對 | 轉移注意、改變姿態或說話節奏，觀眾能讀出與中性的差異 |
| E3 強烈 | 情緒主導當下應對，明顯打斷動作／語流或形成持續張力 | 停下原動作、急切逼問、難以維持平穩呼吸或刻意用力控制反應；仍保有控制 |
| E4 壓倒性 | 情緒達到當場峰值，原有控制或行動能力被突破、停滯或重組 | 爆發、失語、僵住、笑到說不完或悲痛到無法回應；不必大吼、大動作或流淚 |

分開寫兩個判斷：

- **內在強度 `felt`**：角色實際承受的感受，由原文、利害與當下已知資訊推定。
- **外顯強度 `shown`**：預定讓觀眾從表演讀到的該情緒強度，由表情、行為與聲音承載；不是音量或動作幅度。僵住、低聲或緩慢動作仍可能外顯 E3／E4。

有壓抑、掩飾或偽裝時才讓兩者明顯分離，寫清原因及觀眾可讀到的殘餘線索。例如恐懼 felt E4、shown E1，因敵人在門外而強忍反應；若劇本要求完全不露痕跡，可為 shown E0，不硬加洩漏情緒的動作。偽裝成另一種情緒時另記其種類與外顯強度，例如憤怒 felt E3／shown E0，表面親切 E1。線索的可見／可聽對象仍須符合故事視點。不能用「人物內斂」把所有高潮一律降成微表情，也不能因內在強烈就破壞劇本要求的掩飾。

依下列順序選級，替重要選擇附一行來源或理由：

1. **讀明示證據。** 優先採原文的動作、說話方式、感受及使用者要求；記原句或節拍位置。不要用驚嘆號數量、情緒關鍵字或「高潮」標籤機械給級。
2. **按角色所知判斷利害。** 誰的目標受阻、失去什麼、威脅多近、是否有退路？逐人判斷；觀眾知道的秘密不能讓尚未知情的人提前恐懼。
3. **接前態與觸發。** 寫起始、峰值、結束的情緒種類與 felt／shown 強度；峰值可在開頭或結尾，平穩節拍可三者相同。升級、回落或反轉都要有事件、時間流逝或控制行為支持；切鏡不會自動歸零。
4. **決定如何表露。** 依當場目的、關係、性格與作品風格決定外顯方式。寫實、自然或保留角色身分不等於弱化；強烈喜悅、冷怒、恐懼與失語悲痛各有不同表現。
5. **反查辨識度。** 所選動作與語氣是否能區分這一級和較弱／較強的版本？若 E3 仍只有「微微皺眉」，補上符合情節的持續張力、動作中斷或聲音變化。證據不足時做可解釋的創作推定並標明，沿用既有風格與授權，不固定選低級，也不為例行選級反覆詢問。

只為有情緒意義的節拍及角色記錄，不把每幀或每個字都打分。保留日常段落、蓄勢與回落的差異；修正偏弱時提升缺失的表演，不把全片一律設成 E3／E4。

## 把情緒寫成可表演的過程

每個重要情緒節拍交代「初始情緒 -> 觸發 -> 可見／可聽反應 -> 末態」。同時說清角色想隱藏或表達什麼，例如試圖鎮定卻控制不住呼吸、想求助又怕門外聽見。讓表情、眼神、呼吸、姿態、手部與動作速度承載變化，選與當場有關的證據即可。

把所選 shown 強度轉成少數可辨識的表演錨點，通常選兩三個彼此配合的線索即可，不要求眉、眼、嘴、手、呼吸全部同時動作。交代觸發後何時出現、維持多久與如何收尾；多人同鏡各有自己的反應。強度提高可以是動作突然停止、凝視持續或語流破裂，不必增加動作數量。

逐句表演（`delivery`）記語速與節奏、音量、重音、停頓、氣息及聲音變化，讓它們對應說話意圖。角色的音色、年齡感與語言習慣可固定；當下語氣隨情境改變。心聲的空洞聽感同樣保留驚愕、喜悅、憤怒或壓抑等表演。

情緒強度與發聲速度分開決定，緊張、低聲或悲傷不自動等於慢速；E0–E4 不映射到 `rate_multiplier` 或片長。新語音製作依 [對白估時與語速](dialogue-pacing.md) 保留自然發聲目標；確實需要加快、放慢或句內中斷時，依表演試讀／估計安排。實測 `measured_utterance_seconds` 已含句內停頓，不再重複加算；句後停頓與末段反應分別用適用的 `pause_after_seconds`／`reaction_seconds`。較長鏡頭的餘裕留給動作、聆聽與反應，不能拉長每句台詞來填滿。

鏡頭距離、運動、留白、環境聲與配樂配合這個進程。為認出、吸氣、猶豫、吞回話語與反應留時間；動作或台詞容納不下時，調整時長、台詞安排或拆鏡。音樂與音量不能單獨證明角色已演出所需情緒。

情緒節拍可以在同一段完整互動或連續鏡頭內發展，不因級別改變就逐級切鏡。依 [段內時間線](intrashot-staging.md) 選足以完成過程的生成長度；分次生成仍承接實際動作、情緒與聲音末態。

同樣是恐懼，依劇本需要選不同表演；下表是對照寫法，不是每個角色必須依序走完的固定動作表：

| 劇本依據與目標 | 可見／可聽的差異 |
| --- | --- |
| 門外有不明聲響，只有輕度疑慮；felt／shown E1 | 視線短暫移向門口，回答稍慢，仍繼續收拾手邊物件 |
| 聲響重複、需要確認；felt／shown E2 | 停下收拾、轉向門口聽，語句變短，注意力已離開原工作 |
| 認出曾威脅自己的人就在門外；felt／shown E3 | 原動作驟停，呼吸卡住、手緊抓手機；第一句短促受阻，停半拍後急促壓低說完，再後退 |
| 對方已破門、角色一時無法應對；felt／shown E4 | 身體僵住、視線鎖在威脅上，試圖說話卻發不出完整語句；後續逃跑須另有恢復行動的節拍 |

E3 的台詞若是「是他！他就在我家門口！」，可將重音落在「我家」，因怕被聽見而壓低音量，卻保持中斷的呼吸、急促語流與後退。低音量仍有強烈恐懼，不能改成平穩耳語。相鄰玩笑段則按其目標等級放鬆臉部與身體，讓聲音帶笑，形成可辨反差。

同樣檢查正向情緒與低活動的強情緒。例如苦等的好消息終於確認，喜悅 E3 可由愣住後鬆肩、笑出聲並激動地重複一句既有台詞承載；普通被稱讚的 E1 則可短暫微笑後繼續工作。喪失重要人物後的悲痛 E4 可是伸手到一半停住、目光失焦、嘗試回應卻失語。這些都依來源選用，不擅自加台詞、哭喊或改變人物動機。

## 發聲方式與嘴型

逐個語音單位標出說話者、文本、發聲方式（`voice_mode`）、表演、嘴型、聲音聽感／位置、可聽對象及時點。以下是製作標註，並非模型自帶的參數或特殊標記。

| 發聲方式 | 聲音與可聽對象 | 畫面表演／嘴型 |
| --- | --- | --- |
| 口說 `spoken`（含耳語） | 故事現場實際出聲，有符合空間的方向與距離 | 說話角色有對應台詞的發音嘴型；低聲／耳語仍屬口說 |
| 心聲 `inner` | 觀眾聽見角色內心話；預設其他角色聽不見。沿用角色身份，較口說空洞、帶輕微內在共鳴或短殘響，保持清楚與情緒 | 當事角色沒有這句話的發音嘴型；可自然呼吸、吞嚥、驚愕微張嘴或以眼神反應 |
| 無聲的說話 `silent_mouthed_inner` | 現場沒有口說聲，觀眾聽見同一句心聲，聽感沿用 `inner` | 角色無聲地做出這句話的發音嘴型，與心聲對應同一時窗；只有這個指定模式將嘴型與心聲結合 |
| 畫外口說 `offscreen_spoken` | 人在鏡頭外實際說話，例如門後呼喊，有現場位置與遮擋聲學 | 在鏡人物按自己的行為反應，不替畫外人物做發音嘴型；這不是其心聲 |
| 旁白 `narration` | 由敘述者或回述者提供敘事層聲音，按觀點與內容表演；標明是否為同一角色回述 | 不因此要求在鏡角色同步說出旁白，其他人物仍按各自語音單位表演 |

嘴型規則作用於當句指定角色與時窗。同鏡另一人正在口說時，仍保留其發音動作。心聲、旁白或純粹沉默都不自動要求所有可見人物整鏡緊閉嘴唇；「無聲的說話」必須明確編成嘴型加心聲，而非一般心聲或只有嘴型的靜音畫面。

採用 `dialogue_timing.py` 時，先將上述創作標註對應到其實際支援的模式；畫外口說 `offscreen_spoken` 對應 `offscreen`。目前 compiler 不支援 `silent_mouthed_inner`，不可直接送入，也不可靜默改成禁止發音嘴型的 `inner`；保留原表演要求與能力缺口，另確認可用工具，不能宣稱已完成該模式交接。

例如同一句「別出聲。」：心聲版以緊繃眼神與壓住呼吸表達，嘴唇不發音，觀眾聽到急切而略空洞的內心聲；無聲說話版則讓角色朝對方做出這句話的嘴型，觀眾仍只聽到同一句內心聲。人物可知道哪些資訊、對誰的聲音反應，須符合其實際可聽／可見範圍。

為心聲設計的空洞處理套在該聲部，保留聲線辨識、字句清晰與表演；現場環境音及其他角色的口說維持自己的空間。若原生生成不能可靠區分音色處理或口型，採支援的控制或獨立配音／後製，並驗實際結果；提示文字本身不保證模型達成。

## 從標註交接到最終提示

以下欄位按當次需要填在劇本／分鏡，不必另建一套 backend schema：

```text
場次／節拍：角色目標、利害、情緒進程、觀眾感受
每位角色：劇本依據／推定理由、情緒種類、felt 與 shown 的起始 -> 峰值 -> 結束（E0–E4）
表露方式：壓抑／偽裝的原因（若有）、另一種表面情緒及其強度（若有）
鏡頭：觸發與時點 -> 符合 shown 強度的表情／行為／聲音錨點 -> 末態與下一鏡交接
逐句：說話者、原文、voice_mode、delivery、嘴型、聲音位置／聽感、可聽對象、時點
聲線身份：跨鏡保留的音色／語言習慣，與本句表演分開
驗收證據：區分目標強度與偏弱／過度的可見反應和語氣、語音期間應有或不應有的發音動作
```

將上述含義寫入模型實際接受的畫面、動作、語音描述或後製設定。逐句 `delivery`、`voice_mode`、嘴型與聲音處理不能只留在分鏡 metadata。用編譯器時比對其真正序列化輸出；漏讀或被共用預設覆蓋時，提交前修正。使用者指定的敘事口吻與表演風格仍優先保留。

對重要情緒轉折，追到最終提示中對應的動作／表情和當句表演，確認觸發、強度與說者、聽者的反應仍相連。前製的 `emotion_start`／`emotion_trigger`／`emotion_reaction`／`emotion_end` 及 felt／shown 分級都是內容標註；若當次前製工具只讀 `visual_prompt_en` 與逐句 `delivery`，就先將含義寫進這些實際讀取的內容，再核對輸出。Studio 的生成 adapter 實際讀取編譯後 job 的 `shot.prompt`，不會因保留了額外情緒標註就自動編譯分級。把級別轉成自然語言的表演過程，並將目標及可觀察證據寫入該 shot 的 `criteria`；欄位存在或成功複製共用語氣不代表完成交接。

使用新版語音 compiler 時，視覺／動作放進 base prompt，逐句語氣放進 `dialogue_timing.utterances[].delivery`，原台詞只放 `text`；base 不預放 `<d>` 台詞或另一套對白時窗。felt／shown 等創作欄位留在 shot 的附加標註／criteria，不塞入有欄位白名單的 timing 物件或 utterance。核對 `dialogue_timing_result` 與編譯後的實際 prompt，確認強度錨點、逐句語氣、嘴型及停頓目標仍相容；`delivery` 的文字不會自動重算發聲秒數。

共用聲線描述只承載身份與長期特徵，逐句表演直接帶入當場的語音描述；不要把「平靜／輕柔／平穩」固定成每句語氣。檢查情緒標註、發聲方式、嘴型及共用提示之間的衝突，例如本句要求慌亂低喊，實際輸出卻只留下平穩的共用語氣，或無聲說話同時套上禁止發音嘴型的預設。依 [人物參照](character-references.md) 區分身分基準與當鏡表情，避免把中性表情列成整段必須保留的屬性。

E0–E4 不對應固定 CFG、guidance、LoRA 權重、音量或語音 tag，不新增假定 backend 可用的 `emotion_level` 控制。不要以 `(anger:1.5)`、重複形容詞或全域「更激動」代替具體過程；只有所選工具確實提供且已核對的控制才可使用。

台詞文字與表演／音效指示依模型介面分開；需翻譯提示時保留原語言台詞和表演意圖。模式標註不是可直接送入 backend 的新欄位，也不是可任意發明的語音 tag。H3 的對應寫法見 [H3 提示契約](../../minimax-h3-colab/references/official-prompting.md#本地表演與發聲方式交接)。

## 審稿與實際聲畫驗收

生成前審查角色的目標、情緒觸發、強度依據、轉折、逐句表演、發聲方式、嘴型與跨鏡承接是否一致，並抽查最後真正要提交的提示。單有「恐懼」「開心」或「E3」標籤，尚不足以交代如何表演。特別核對劇本的峰值沒有被統一寫成「稍微／微微／克制」，同時保留有依據的壓抑與低強度段落。

實際製作時，依不確定性選能辨別情緒反差或發聲／嘴型模式的短片驗證，再安排其餘生成；沿用當次預算與試驗範圍，不為每種情緒固定增加試片。

審片時對照預定的具體反應與語音時窗：情緒為何改變、觀眾能否從表情／行動讀到，是否聽到對應的停頓、重音、氣息與語氣，心聲是否較空洞且仍有情緒，嘴型是否符合當句模式。檢查心聲沒有讓角色無故變成現場口說，無聲說話也確實保留嘴型與內心聲的對應。修改或選材後複查受影響處與接點。

另判斷**強度是否足夠且適量**：應有的動作中斷、持續張力或語流變化是否可讀？與前後較弱節拍有無差異？反應是否在正確觸發後出現，結束狀態有無無故歸零？比較預定 shown 與實際證據，不從表情宣稱量出角色的 felt，也不把安靜等同情緒弱。偽裝或完全不露痕跡的片段按其原定可見內容驗收。

在現有評審理由中區分「偏弱」「過度」「情緒／意圖錯誤」「轉折時機錯誤」或「證據不足」，附時間與具體表現；不新增機器 verdict。能看出情緒種類、但不足以達到既定強度仍可為 fail；未看清或未聽驗則為 unknown。級別比較是有依據的創作判斷，不偽裝成客觀小數分數或用平均分放行。

語氣、空洞聽感與情緒節奏需實際聽驗／觀看；語音期間的嘴型用實際播放或足夠的連續影格確認。ASR 字句正確、音量達標或單張閉嘴畫面各只能證明其覆蓋的事實。依 [驗收與放行](../../colab-video-studio/references/video-review.md) 記錄 pass／fail／unknown 與能力限制；未聽驗的表演保留 unknown，使用者對情緒的實際回饋優先。

## 表演偏弱或過度時的修正

先定位缺口，再在既有預算與授權內修正受影響片段：

1. 對照劇本與 felt／shown：是分級選錯、缺乏可讀錨點，還是有理由的壓抑？不要只提高數字而保留同一段模糊表演。
2. 比對實際 prompt：有無漏掉強度對應的動作、翻譯弱化、共用平穩語氣或互斥的正／負面提示？先修交接，不用盲目重抽彌補漏傳。
3. 核對實際參考圖、首尾幀與 retention：身分保留是否誤鎖表情？起幀與目標起態不合時，沿用身分基準另備當鏡圖，或在不改情節的前提下安排合理轉變；不能要求已固定的首幀同時是兩種狀態。
4. 檢查景別、遮擋、節奏與聲音：必要反應是否小到看不清、被台詞填滿或剪掉？只調整足以呈現證據的取景、時間或表演，不能靠放大音量／配樂替代。
5. 對缺失或過度的具體線索修 prompt、表演素材或配音，保留角色身分、情節、發聲方式及相鄰接點。需要試片時選能辨別此問題的短段；同條件無界重抽與全片升級都不算診斷。取得實際聲畫後再記結果，未生成只記準備完成。
