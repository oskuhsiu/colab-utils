# 情緒與表演：從劇本到實際聲畫

含角色表演、對白或內心話的敘事片在生成前使用本頁。局部修正只處理受影響的表演與接點；單純轉檔、裁切或無角色的素材處理不必建立整套情緒設計。此頁是共用製作規則；各模型的提示語法與能力另按其輸入契約。

## 先寫角色為何有感受

在劇本階段整理每場的角色目標、在乎的得失、知道與誤解的資訊，以及新事件如何改變其情緒；另記希望觀眾感受到什麼。角色當下的感受與觀眾的感受可以不同，例如角色自得其樂，觀眾已從背景察覺威脅。

按事件安排情緒進程與反差，延續前場實際末態。場景切換本身不表示角色已冷靜；必要的緩和、掩飾或情緒反轉要有理由。刻意冷靜、麻木或死寂也可服務故事，明確交代其用途與其他角色的反應，而非讓所有角色共用一種平讀語氣。

把心理描寫分配給可見反應、行動、必要心聲或旁白；按故事的敘述觀點選擇，保留重要原意。原文的「想／心道」、說話動詞、唇語動作與改編安排是判斷發聲方式的依據。

## 把情緒寫成可表演的過程

每個重要情緒節拍交代「初始情緒 -> 觸發 -> 可見／可聽反應 -> 末態」。同時說清角色想隱藏或表達什麼，例如試圖鎮定卻控制不住呼吸、想求助又怕門外聽見。讓表情、眼神、呼吸、姿態、手部與動作速度承載變化，選與當場有關的證據即可。

逐句表演（`delivery`）記語速與節奏、音量、重音、停頓、氣息及聲音變化，讓它們對應說話意圖。角色的音色、年齡感與語言習慣可固定；當下語氣隨情境改變。心聲的空洞聽感同樣保留驚愕、喜悅、憤怒或壓抑等表演。

鏡頭距離、運動、留白、環境聲與配樂配合這個進程。為認出、吸氣、猶豫、吞回話語與反應留時間；動作或台詞容納不下時，調整時長、台詞安排或拆鏡。音樂與音量不能單獨證明角色已演出所需情緒。

例如「是他！他就在我家門口！」：認出老人後呼吸中斷、肩膀縮回、手握緊手機；第一句短促而卡住，停半拍後第二句壓低且急促，重音落在「我家」，說完急退。情緒來自認出與威脅迫近，並有試圖壓住驚恐的行為。相鄰的玩笑段可以讓臉部、身體放鬆，聲音帶笑與得意的節奏，形成可辨認的反差。

## 發聲方式與嘴型

逐個語音單位標出說話者、文本、發聲方式（`voice_mode`）、表演、嘴型、聲音聽感／位置、可聽對象及時點。以下是製作標註，並非模型自帶的參數或特殊標記。

| 發聲方式 | 聲音與可聽對象 | 畫面表演／嘴型 |
| --- | --- | --- |
| 口說 `spoken`（含耳語） | 故事現場實際出聲，有符合空間的方向與距離 | 說話角色有對應台詞的發音嘴型；低聲／耳語仍屬口說 |
| 心聲 `inner` | 觀眾聽見角色內心話；預設其他角色聽不見。沿用角色身份，較口說空洞、帶輕微內在共鳴或短殘響，保持清楚與情緒 | 當事角色沒有這句話的發音嘴型；可自然呼吸、吞嚥、驚愕微張嘴或以眼神反應 |
| 無聲的說話 `silent_mouthed_inner` | 現場沒有口說聲，觀眾聽見同一句心聲，聽感沿用 `inner` | 角色無聲地做出這句話的發音嘴型，與心聲對應同一時窗；只有這個指定模式將嘴型與心聲結合 |
| 畫外口說 `offscreen_spoken` | 人在鏡頭外實際說話，例如門後呼喊，有現場位置與遮擋聲學 | 在鏡人物按自己的行為反應，不替畫外人物做發音嘴型；這不是其心聲 |
| 旁白 `narration` | 由敘述者或回述者提供敘事層聲音，按觀點與內容表演；標明是否為同一角色回述 | 不因此要求在鏡角色同步說出旁白，其他人物仍按各自語音單位表演 |

嘴型規則作用於當句指定角色與時窗。同鏡另一人正在口說時，仍保留其發音動作。心聲、旁白或純粹沉默都不自動要求所有可見人物整鏡緊閉嘴唇；「無聲的說話」必須明確編成嘴型加心聲，而非一般心聲或只有嘴型的靜音畫面。

例如同一句「別出聲。」：心聲版以緊繃眼神與壓住呼吸表達，嘴唇不發音，觀眾聽到急切而略空洞的內心聲；無聲說話版則讓角色朝對方做出這句話的嘴型，觀眾仍只聽到同一句內心聲。人物可知道哪些資訊、對誰的聲音反應，須符合其實際可聽／可見範圍。

為心聲設計的空洞處理套在該聲部，保留聲線辨識、字句清晰與表演；現場環境音及其他角色的口說維持自己的空間。若原生生成不能可靠區分音色處理或口型，採支援的控制或獨立配音／後製，並驗實際結果；提示文字本身不保證模型達成。

## 從標註交接到最終提示

以下欄位按當次需要填在劇本／分鏡，不必另建一套 backend schema：

```text
場次／節拍：角色目標、利害、情緒進程、觀眾感受
鏡頭：初始情緒 -> 觸發 -> 表情／行為／聲音反應 -> 末態與下一鏡交接
逐句：說話者、原文、voice_mode、delivery、嘴型、聲音位置／聽感、可聽對象、時點
聲線身份：跨鏡保留的音色／語言習慣，與本句表演分開
驗收證據：應看見的反應、應聽見的語氣、語音期間應有或不應有的發音動作
```

將上述含義寫入模型實際接受的畫面、動作、語音描述或後製設定。逐句 `delivery`、`voice_mode`、嘴型與聲音處理不能只留在分鏡 metadata。用編譯器時比對其真正序列化輸出；漏讀或被共用預設覆蓋時，提交前修正。使用者指定的敘事口吻與表演風格仍優先保留。

對重要情緒轉折，追到最終提示中對應的動作／表情和當句表演，確認觸發與說者、聽者的反應仍相連。前製的 `emotion_start`／`emotion_trigger`／`emotion_reaction`／`emotion_end` 是內容標註；若當次編譯器只讀 `visual_prompt_en` 與逐句 `delivery`，就先將轉折含義寫進這些實際讀取的內容，再核對輸出。欄位存在或成功複製一份共用語氣，不足以證明當段情緒已傳入。

共用聲線描述只承載身份與長期特徵，逐句表演直接帶入當場的語音描述。檢查情緒標註、發聲方式、嘴型及共用提示之間的衝突，例如本句要求慌亂低喊，實際輸出卻只留下平穩的共用語氣，或無聲說話同時套上禁止發音嘴型的預設。

台詞文字與表演／音效指示依模型介面分開；需翻譯提示時保留原語言台詞和表演意圖。模式標註不是可直接送入 backend 的新欄位，也不是可任意發明的語音 tag。H3 的對應寫法見 [H3 提示契約](../../minimax-h3-colab/references/official-prompting.md#本地表演與發聲方式交接)。

## 審稿與實際聲畫驗收

生成前審查角色的目標、情緒觸發、轉折、逐句表演、發聲方式、嘴型與跨鏡承接是否一致，並抽查最後真正要提交的提示。單有「恐懼」「開心」標籤，尚不足以交代如何表演。

實際製作時，依不確定性選能辨別情緒反差或發聲／嘴型模式的短片驗證，再安排其餘生成；沿用當次預算與試驗範圍，不為每種情緒固定增加試片。

審片時對照預定的具體反應與語音時窗：情緒為何改變、觀眾能否從表情／行動讀到，是否聽到對應的停頓、重音、氣息與語氣，心聲是否較空洞且仍有情緒，嘴型是否符合當句模式。檢查心聲沒有讓角色無故變成現場口說，無聲說話也確實保留嘴型與內心聲的對應。修改或選材後複查受影響處與接點。

語氣、空洞聽感與情緒節奏需實際聽驗／觀看；語音期間的嘴型用實際播放或足夠的連續影格確認。ASR 字句正確、音量達標或單張閉嘴畫面各只能證明其覆蓋的事實。依 [驗收與放行](../../colab-video-studio/references/video-review.md) 記錄 pass／fail／unknown 與能力限制；未聽驗的表演保留 unknown，使用者對情緒的實際回饋優先。
