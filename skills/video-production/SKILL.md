# 通用影片製作

依使用者目的完成實際需要的影片或指定工作階段。先釐清必要限制，再用適合題材、素材與工具的流程；單鏡、簡單剪輯或純審查不必套用整套多鏡製作。沿用已給的授權和選擇，例行創作決定自行處理；只有缺少會改變結果、可行性或授權的資訊時才詢問。

## 確立作品與方法

1. 確認目的、受眾、素材／來源、重要內容與交付規格：時長、畫面比例、風格、語言、聲音、字幕、格式、平台，以及使用者指定的工具、預算和期限。未指定時按情境選合理設定，不套用其他作品的時長、畫風、GPU 或模型。
2. 查看可用素材與實際工具能力，決定使用拍攝、既有影片、動畫、生成、剪輯或混合方式。核對模型是否真能接收需要的參考圖、前後幀、影片控制或聲音；使用者指定工具時不要悄悄替換。若工作是在 Colab 而且 `colab-video-studio` skill 可用，配合其專用流程；其他環境採對應工具與版本的實際介面。
3. 區分必須保留的事實／情節、使用者授權的改編，以及可自行決定的取景或節奏。既有影片的局部修正以指定問題為範圍，保留可用素材與舊版；若要改內容或新增橋接，確保不憑空改變原意。

## 內容、分鏡與連續性

對有敘事或說明目標的影片，先整理觀眾需要看懂的事件、因果、情緒或重點。改編文字時，能由畫面、動作和環境聲表達的資訊優先安排可見證據；旁白、講解或對白仍按作品需要使用。除非使用者指定朗讀或作品形式需要，避免把整段環境描寫直接變成口播。

小說／短劇改編、跨集資產整理或劇本轉逐鏡提示時，讀 [短劇前製](references/drama-preproduction.md)，使用其中的劇本、資產與鏡頭交接模板。它補充分鏡前的內容整理；實際生成仍按所選模型的輸入契約與既有製作流程執行。

多鏡作品先安排必要的段落與時長。分鏡至少交代該鏡目的、主體與場景、景別／運鏡、可辨認的動作、起點和終點、接下一鏡需要保留的狀態，以及需要的聲音、台詞和參考素材。詳盡程度與任務相稱；留時間讓動作、情緒或講解被理解，勿只按鏡數平均分配時長。內部分鏡的鏡數與秒數是工作假設，除非使用者指定，隨實際素材調整並更新選材／剪輯時間軸。

多場次的故事／小說改編，主代理先整理全片節拍與共用設定，再使用可用的 subagent 分工拆幕、逐幕細化分鏡。依子任務的複雜度、歧義與上下文量選擇模型及 effort，遵守宿主與專案的代理路由。委派時給出原文範圍、必留情節、共用角色／場景／建築基準及相鄰段落的交接條件，要求依上述欄位回傳逐鏡內容與待解問題。主代理整合後核對原文覆蓋、重複或遺漏及節奏，並完成下述連續性審查再進入製作。簡短單幕或撰寫代理不可用時，分鏡可由主代理撰寫，仍須交由另一位 agent 審查。

設置一位未參與分鏡撰寫的專責連續性審查 agent，持續負責全片；每段分鏡完成後立即交審。主代理提供原文、全片節拍、共用角色／場景／建築設定、當段與可用的前後相鄰分鏡，以及已有的選定素材。審查者逐鏡核對段內動作、因果與資訊是否連續，再檢查跨段接點，不能只看各鏡描述是否完整。

逐個檢查重要接點：觀眾能否知道誰在哪裡、剛做了什麼、為何會進入下一個狀態；人物位置與方向、服裝、道具、建築外觀與出入口、空間布局、光線、時間和因果是否接得上。未安排時空轉場的相鄰分段，後段起態應承接前段實際末態；切換景別或生成片段邊界本身不表示場景與人物狀態已改變。需要時補可見的轉身、移動、反應、物件交接或建立空間的鏡頭；轉場、淡化或音效不能單獨證明缺失的動作。以觀眾可讀的因果與前後態為準；合理遮擋不必要求每個肢體或像素全程可見。回憶、蒙太奇與刻意跳時可保留跳接，但要給觀眾理解時空轉換所需的線索。

審查結果按段落／鏡頭 ID 記錄通過、需修正或待確認，指出衝突的前後狀態、缺少的動作或資訊及理由。主代理安排修正，再交審查 agent 複查受影響段落與接點；該段及當時可查的接點通過後才進入該段製作。後段尚未完成時，後接點保持待確認，於後段完成後補查；改動已審分鏡或換選材時，重查受影響範圍。審查 agent 不可用時，保留未審狀態並說明限制，不以撰寫者自檢宣稱獨立審查通過。

跨鏡一致性重要時，先確定人物、動物、服裝、關鍵道具及場景／建築的外觀和空間基準。優先沿用使用者提供或已選定的素材；需要從文字創造角色，或缺少可用的場景／建築與關鍵道具基準時，主動依 `imagegen` skill 製作設定圖，除非使用者指定其他工具。按作品選定的畫風檢查並固定共用設定，把選定圖與提示存入當次專案，讓各鏡沿用；必要時補足可辨識建築與空間的不同視角。

把角色／場景基準與前鏡實際末態用作後鏡條件時，確認所選工具真正支援；參考圖或末幀本身不保證生成結果會連續；驗證實際後鏡再沿用此方法。身分／空間基準與該鏡構圖分開選材，多視角設定表或不相容的全景可能把構圖拉回錯誤狀態；必要時只取相關角色或道具裁切。逐鏡提示只描述當下到預期末態，避免混入未來情節或互斥狀態。若工具支援實際動態尾段作控制，可有界試用重疊生成後剪掉重複前綴，仍需驗證接點。

敘事成片在分鏡階段就主動安排語音與音效：為有台詞的角色維持一致的聲線、語言和表演方式，把對白、必要旁白、環境聲與動作音效對應到鏡頭及時點。依實際能力採原生聲畫生成或獨立配音／音效後製，預留台詞、動作與反應時間，並將音軌合入成片驗收。沒有台詞的片段可由環境聲與音效承載；新增對白須符合故事與改編範圍，無聲或無對白要求依使用者選擇。

## 製作、資源與修正

- 先備妥下一步能用的素材、輸入與保存方式。需要驗證生成能力、角色或接點時，先做能暴露關鍵問題的短試片；再按實際結果生成與選材。畫面說明、音效和正式台詞依模型介面分清；若模型把指令念出來，針對實際輸出修正並複核。
- 以可回溯的方式保存必要來源、所選素材、實際提示／設定和剪輯版本；重要片段完成後及時保存。與原有工作隔離，修正版另存，避免覆寫使用者檔案。簡單任務不必建立龐大的製作紀錄。
- 有付費資源或時間上限時，核對可取得的計價、用量與當次限制；若指定硬體，確認實際分配，若有預算上限，核對剩餘預算與停止餘量。將等待、下載、載入、生成、重試、保存和釋放都計入。續作與重跑累計同一已授權預算，除非使用者明確調整；不要把帳戶餘額當成本次可用額度。用實測完整製作循環估算剩餘時間，包含選材、審閱和修正，分開一次性啟動與持續成本；把不依賴付費運算的整理和後製移到釋放後，驗證集中在會影響觀感或因果的問題。成本或執行時間有風險時設可行的監控／停止措施；如使用可持續計費的資源，保存必要成果後釋放並確認狀態。
- 分清呼叫已啟動、取得佇列收據、產出可用媒體與內容驗收；控制或傳輸通道失聯不代表計費資源已停止。中斷、超時或結果未明時先查原作業狀態與已產出檔案，再決定恢復或重試，避免重複提交與計費。針對可確認的缺陷修正受影響的鏡頭和接點；在既有授權與限制內完成必要重抽。超出預算、違反工具指定或其他超出授權的變更，不得自行執行。

## 剪輯與驗收

修正時保留已成立的動作；過載的一鏡可拆成相接的動作，或以狀態相容的反應／插入鏡重剪。畫外暗示須符合來源敘事，不能用聲音或文字宣稱素材中沒有、而故事又必須看見的事件。

剪接前後核對實際內容與順序，而不只看單張好看的畫面。依片型檢查重要事件是否可讀、角色與場景是否符合基準、各段之間的動作和狀態是否連貫，以及開頭和結尾是否成立。對較快、遮擋或易漏的動作用足夠密度的連續影格檢查；使用者指出影片有跳躍時，優先對照實際成片定位前後狀態，再決定重剪或補拍。

有語音、音效、音樂或字幕時，檢查其內容、聲畫時間、段落銜接與混音是否符合需求。裁切、變速、倒放或替換畫面／音軌後重查受影響區間，尤其台詞首尾和動作對應的聲音；不能因畫面倒放就假設原音仍同步。ASR 可輔助核對台詞，但同音字或漏字需回查原音；聲音波形或音量不等於辨認出指定音效。

使用 stream copy 串接時，相同編碼與標稱影格率仍可能因時間基準、時間戳或各段音軌長度不同而產生錯誤片長／錯位；按實際差異統一必要參數或重編碼，再核對實際時間軸、音畫起訖與結尾完整性。

對最終版本核對時長、格式與所需音畫軌，並做適當的播放／解碼和內容檢查；可即時播放及聆聽時，以實際速度看完整作品與重要接點。連續抽幀、ASR、音量與成功解碼各只能支持其覆蓋的事實，不能代替完整觀影、聽感或故事節奏判斷。使用者對成片的實際回饋優先於先前技術檢查；修改後重驗受影響的內容與接點。成片的獨立審查在有助於結果且可行時使用，不把自檢稱為獨立審查。

## 交付

提供可取得的最終影片，並簡述時長、關鍵改動和實際執行的驗證。保留與任務相關的素材、分鏡、選材或剪輯資訊，方便後續修改；如有付費資源，說明實際或估算用量的口徑及釋放狀態。對未能實際檢查的播放、聽感、音效或其他重要要求明確標示範圍與限制，不把準備完成、技術可解碼或抽樣結果稱為完整品質通過。
