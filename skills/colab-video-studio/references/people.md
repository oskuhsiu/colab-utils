# 人物、外觀基準與適配器

指定人物、虛構角色、外觀一致性或 LoRA 需求時讀。人物身份、服裝、動作與聲音是不同條件。

## 基準與實際輸入

指定照片以原始人物素材為身份基準；虛構人物以已選定的角色圖為基準。記錄每張素材提供身份、服裝、構圖還是風格，保留衍生關係。多張同人素材定義成同一人物；同人定裝圖不是另一位演員。

新建或補製人物圖時，先依 [人物參照](../../video-production/references/character-references.md) 準備身分、臉部近景及所需角度，核對各衍生圖；人物基準、場景與當鏡起幀分工。資產庫覆蓋與 job 實際收到的圖片分開記錄，依當鏡用途和模型的圖片上限選圖；尚未驗證模型能解讀多視圖表時，優先使用相關的單一視圖。

檢查真正送入模型的 resize／crop：保留需要的五官、髮型或服裝特徵，排除無關人物／配件並記座標。裁切可取捨資訊，不能重建未提供的視角或鎖定影片像素。生成的關鍵幀／定裝圖回到原始基準比對，避免用漂移的生成臉逐代取代身份。

原照直接作首尾幀時，記為端點條件；只傳衍生端點圖時，不宣稱原照也直接送入。若宣稱原照另外作身分參考，需有實際 identity/reference 分支。模型提供 reference 輸入不保證原臉效果。驗收使用 [video-review.md](video-review.md#通用驗收) 的當次人物判準。

## 選擇適配器

| 目的 | 需核對的契約 |
| --- | --- |
| 少步數推論 | distillation／speed adapter 與 checkpoint、scheduler、native steps 相符 |
| 人物外觀 | identity adapter 的訓練對象、trigger、基模與 loader 支援 |
| 風格／細節 | style adapter 的作用範圍；效果不自動涵蓋身份或動作 |
| 時序／結構 | control adapter 的實際 pose／layout／其他輸入與前處理 |

採用權重前記錄來源／revision、hash、rank／alpha、scale、trigger 和相容 loader；核對實際 patch target，再用符合當次要求的內容驗證。H3 比例與模式由 H3 skill 管理。此 repo 的 Wan-Animate adapter 不接自訂 LoRA；其他未接入組合先保持候選狀態。

## 身份後製與訓練

作品採用身份後製時，保留原生影片和原照→實際工具輸入→輸出的來源鏈，原生模型 verdict 另列。試做需涵蓋相關的表情、轉頭、遮擋及手／道具接觸；工具完成一張臉不構成時序品質證據。記錄實際 job 參數與 provider，參數數字按該版本的公式理解。把初始化、處理與驗收耗時列入交付路徑，即使在本機免費執行。

訓練是額外工作：先確認資料、模型／trainer 相容性、硬體與儲存和當次授權，分離 training／held-out 來源，再驗固定身份與目標動作。合成變體不等於增加真人未提供的視角證據。成功的工具或單一題材不形成所有人物的保真保證。
