# 相機與構圖

需要人物移動、起身、跨越邊界或指定運鏡時讀。人物、物件和攝影機的運動分開規劃。

## 取景契約

每鏡列出視角、景別、相機運動的目的與時段，以及重要動作中必須可見的部位／接觸點。用起末構圖和必要中點檢查完整動作包絡與畫面裕量；裕量依動作選擇，不用固定比例保證模型。

全身動作鏡與細節鏡的可見性判準不同。近景可以刻意省略其他部位；指定身份或同框事件仍需安排足夠可讀時段。跨鏡核對視線、運動方向和空間關係，轉軸／改機位時提供可理解的轉場。

## 實際控制層

| 控制方式 | 邊界 |
| --- | --- |
| prompt 描述運鏡 | 表達攝影意圖，效果以影片驗，不是硬軌跡 |
| 首／尾構圖 | 約束可用端點，中途運動另驗；與 reference 能否同用依 adapter |
| pose／layout／driver | 攜帶其實際時序訊號；不自動提供標定相機、手指或物件物理 |
| 專用 camera adapter | 需要匹配權重、座標／時間規格和真正接入的 runtime |
| 後製 crop／pan／zoom | 移動已有畫面的窗口，受原生像素及畫外內容限制 |

本 repo 的 stock Wan I2V 不接 camera path；H3 的端點支援按 H3 skill；VACE／Animate 按 [controls.md](controls.md) 的實際條件。外部相機方案須先完成介面與小片驗證，不能只加一個未支援的 kwargs。

數位重構圖記錄完整 crop／縮放映射，重新驗影格內容與細節。已有出框內容不靠後製窗口恢復。精確速度／路徑要求才加入必要量測，一般鏡頭按可見性與目的驗收即可。
