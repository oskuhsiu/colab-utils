# 來源影片的角色與身體替換

用於需要 pose／face driver、background 或 mask 的來源影片替換。僅做臉部後製時，依該工具真正需要的輸入和 [people.md](people.md) 處理，不自動加上身體驅動條件。

## 控制準備

保存來源影片、目標外觀、實際輸入及 frame／時間映射。確認 index 起算、旋轉、偵測框、resize／crop 與切鏡；按 backend 決定拆段或重置時序。完成條件是輸入可與來源對齊，尚未判替換品質。

檢查解碼後 pose 的人體部位、接觸和前後運動，再參考信心／覆蓋數。門檻從實際呼叫鍊取，不把底層函式預設當最終設定。對跳變、缺點、轉身／遮擋等異常定位後查連續原片；自然翻轉或遮擋不強制改成標準正面站姿。

人工修正／插值記錄受影響影格、可見來源與未觀測部分，重驗所有由該控制衍生的 crop／driver。只有改 metadata 而未檢查重畫影片，尚未完成控制修正。

## 外觀、比例與遮罩

face driver 同時可攜帶來源外貌和表情。角色圖是否蓋過來源身份須用實片驗；空白、固定正臉或粗角度圖是不同條件，不當成中性消融或真實表情／轉頭訊號。

臉部 crop 保持接口需要的尺度；頭飾與全身外觀按相應 reference／編輯範圍提供。比對背景移除區與新 mask 是否允許目標輪廓，來源與目標體型不同時另核對頭身比與肢體。換臉不證明全身比例已改。

retarget、mask 方向和條件組合依 [controls.md](controls.md) 的選定模型／模式；支援在某一模式不代表其他模式也生效。原始 driver 不是已提取的 pose／face 輸入。

## 驗收與修正

分開驗身份、服裝／輪廓、解剖、遮擋、動作因果與接點。對當次重要視角／動作先做可判讀試片；控制錯誤與外觀錯誤各自留假說，改動能區分問題的輸入。近景通過不擴成全身或所有動作通過，驗收規則見 [video-review.md](video-review.md#通用驗收)。
